Firmware slots

The cartridge's flash holds one synthesizer per slot; the FM-1 picks which one boots (GLO → CARTRIDGE → FIRMWARE). Here you read what each slot holds, back up the whole flash and write new firmwares into the slots.

1. Connect the cartridge

  1. Unplug the cartridge from the FM-1 and plug it into this computer.
  2. Put the ESP32 in its USB bootloader: hold BOOT, press and release RESET, release BOOT.
  3. Press Connect and pick the USB JTAG/serial port.

2. Back up the flash

A full image of the flash (bootloader, partition table, the kept sounds in nvs and every slot) to put back with esptool.py write_flash 0 <file> or the "Release image" card below. Writing stays locked until this board has a backup.

Release image (all slots in one file)

A tagged release carries the three synthesizers, the bootloader, the table and a clean otadata in one file per board (fm1-cartridge-esp32s3-4m2m.bin for the Super Mini). It is written at 0x0 and fills the gaps with 0xFF, so it also clears the sounds every firmware kept.

FM-1: Sloop with the cartridge profile

    
The FM-1 needs the Sloop build of this repository (sloop-fm1/build/felucca.fwsc) to play the cartridge. It installs through Sloop's own updater over USB-MIDI, the same as Sloop's installer page.

    
This browser has no Web MIDI with SysEx: use Chrome or Edge, or sloop-fm1/tools/fm1_install.py.
